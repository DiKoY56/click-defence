\# Pivo Defense



2D clicker + tower defense.

Соло-проект на Godot 4.7 (GDScript).



\## Об игре

Отбивай пивной ларёк от волн алкашей: кликай по врагам, строй башни,

прокачивай их и выбирай усиления между волнами.



\## Как запустить

1\. Установить Godot 4.7.

2\. Открыть `project.godot`.

3\. F5.



\## Управление

\- ЛКМ — урон по врагам и всё UI

\- Клик по слоту — меню постройки, клик по башне — прокачка/продажа

\- F11 / Alt+Enter — полноэкранный режим

\- E — отладочный спавн врага



\## Структура

\- `scripts/` — логика (менеджеры, башни, враги, UI)

\- `scripts/data/` — классы ресурсов

\- `assets/data/` — конфигурации врагов/башен (.tres)

\- `scenes/` — сцены, `scenes/maps/` — карты, `scenes/ui/` — интерфейсы

\- `assets/` — арт, звук, шрифты
